# 神諭之間占卜架構改版

## 範圍
以星語塔羅的分步占卜模式為介面參考，沿用神諭之間 24 張原創牌、原牌背、單牌／三牌解讀、知識庫與本機手札。
流程：認識牌組 → 寫下問題 → 選擇單／三牌 → 洗牌及選牌 → 原有解讀。
沒有加入付款、正逆位、擲筊、外部 AI API，沒有更改任何解讀資料 JSON。

## 實際瀏覽器驗收
- 桌面：單牌工作提問，選牌及揭牌成功，原牌義／關係／行動／手札介面保留。
- 桌面：三牌模式先選兩張無法揭牌；選滿三張後揭牌成功，出現現況／阻礙／建議與三牌綜合解讀。
- 桌面：儲存測試手札成功。
- 390px 手機寬度 iframe：首頁四步驟、牌組圖片與按鈕未橫向溢出；手機選單以鍵盤 Enter 開啟，導覽可回新占卜。
- 390px 手機寬度 iframe：完整單牌流程成功，12 個牌背四欄排列，揭牌控制列固定於可見底部。
- 390px 手機寬度 iframe：既有三牌解讀能恢復顯示；本次多分頁手札唯讀狀態有明確提示。
- JavaScript node --check 通過。
